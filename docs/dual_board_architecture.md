# 双板媒体链路：实施边界

本文件概述当前确认的系统边界；包字段和状态机见 [双板媒体实施计划](dual_board_media_plan.md) 及 [媒体链路协议](media_link_protocol.md)。

## 职责与提交边界

媒体板 .3 管 SD/SPI、FAT32、BMP/WAV、播放列表、切图按键、自动轮播、PC 串口/以太网入口和媒体发送。显示板 .2 管本地 SDRAM、HDMI 图像/音频、转场、OSD/字幕/频谱、GT911 与指针。

显示板始终展示当前活动缓冲。媒体帧和配对 PCM 写入非活动区并验证完成后才提交；转场期间继续用旧音频，特效完成后切新音频并回报媒体板。未完成或校验失败不切换活动缓冲。

## UDP 方向

- PC .1 → 媒体板 .3:1：V1 命令/字幕上行。
- 媒体板 .3 → 显示板 .2:1：正式媒体数据和显示侧绝对设置/状态/字幕请求。
- 显示板 .2 → 媒体板 .3:1：READY、图像/音频结果、显示设置 ACK、状态回报。
- 媒体板 .3 → PC .1:2：V1 命令 ACK/A5 状态及 D 调试读回。

媒体板以太网 D 用于按需获取当前已提交图像的正式 PC 快照；UART D 保留原始调试 tap。PC 快照不改变显示 SDRAM 中的活动图像。

## 显示板 SDRAM

显示缓冲沿用 single-board-gt911-v1：

| 缓冲 | 起始 32-bit 字地址 | 容量/用途 |
| --- | ---: | --- |
| BUF0 | 0 | 图像 A，460800 字 |
| BUF1 | 460800 | 图像 B，460800 字 |
| BUF2 | 921600 | 音频 A，587776 字 |
| BUF3 | 1509376 | 音频 B，587776 字 |

音频区继续保留；只有日后音频架构确定改动后再讨论是否释放。

## 验收顺序

1. 媒体板工程独立综合；当前 board_media 使用正式媒体/PCM源和按包路由，资源与时序见双板实施计划。
2. 显示板单板接 PC 媒体模拟器：已知图像/音频、包错误/重试、显示设置、S 状态、字幕；协议 RESULT 验证事务完成，HDMI 画面由板级目视确认。网页 D 正式快照仍由媒体板提供；资源优化移除的只是显示板本地 SDRAM 诊断读回探针。
3. 两板接交换机做 READY、整图、音频、提交回执、N/P/A、显示控制与状态回包。
4. 全链路通过后再从显示板源列表移除旧 SD/FAT/BMP/WAV 读取模块。
5. SPI→SD 读写升级保持为独立后续项目。

具体包类型、字节序、校验、PC/显示目的地址和剩余恢复策略见 [双板媒体实施计划](dual_board_media_plan.md)。

## 当前实现状态（2026-10-21）

媒体板正式图像/PCM/控制链路由 `board_media` 提供；显示板接收媒体、写入双缓冲 SDRAM、播放并回送提交/控制结果。网页 D 正式快照仍由媒体板从 SD 重读已提交图片提供。优化移除的是显示板本地 SDRAM 诊断读回探针，未移除网页 D 功能。OSD 的“关闭、调节后 3 秒、始终显示”模式也继续由 PC 经媒体板转发控制。当前优化版已上板，用户确认功能正常。

资源、WNS、最终 bit 路径及上板验收清单见 [双板媒体实施计划](dual_board_media_plan.md)；逐字段协议和 PC 模拟步骤见 [媒体链路协议](media_link_protocol.md)。
