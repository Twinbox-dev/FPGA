# HC-08 / UART 命令字节表

## 发送格式

已连接的 HC-08 进入串口透传后，手机发出的数据会从 UART TXD 原样送到 FPGA RX。正式媒体固件不是收到一个字节就执行命令，而是等待两字节校验帧：

```text
CMD, ~CMD
```

`~CMD` 是 CMD 按位取反，也就是 `CMD XOR 0xFF`。两字节之间不要插入 CR/LF。UART 参数为 9600 baud、8N1。HC-08 连接后进入串口透传模式，参数依据[官方 HC-08 V3.1 手册](https://www.hc01.com/downloads/HC-08V3.1.pdf)。

手机终端建议用 HEX / raw byte 模式，按表格发送两个字节。例如 `4E B1`。TEXT 模式输入 `N` 只发送一个 ASCII 字节 `4E`，生产固件会继续等待校验字节，不会立刻执行；输入文本 `4E` 则会发两个 ASCII 字节 `34 45`，不是单个 HEX 字节 `4E`。

桌面独立测试项目 `hc08_hex_probe` 的最小探针不做 `CMD, ~CMD` 校验，只显示每个有效 UART 字节；它用于确认手机到 FPGA 的原始数据链路。下面的命令帧表对应本仓库的生产媒体固件。

## 常用控制命令

| 手机按键/含义 | CMD | 完整发送帧 | 作用 |
|---|---:|---:|---|
| N | `4E` | `4E B1` | 下一张 |
| P | `50` | `50 AF` | 上一张 |
| A | `41` | `41 BE` | 自动轮播开关 |
| S | `53` | `53 AC` | 请求状态 |
| + | `2B` | `2B D4` | 音量增加 |
| - | `2D` | `2D D2` | 音量降低 |
| ] | `5D` | `5D A2` | 亮度增加 |
| [ | `5B` | `5B A4` | 亮度降低 |
| . | `2E` | `2E D1` | 对比度增加 |
| , | `2C` | `2C D3` | 对比度降低 |
| > | `3E` | `3E C1` | 自动轮播间隔增加 1 秒 |
| < | `3C` | `3C C3` | 自动轮播间隔减少 1 秒 |

## 切图特效、OSD 与图像效果

| 按键 | CMD | 完整发送帧 | 作用 |
|---|---:|---:|---|
| 0 | `30` | `30 CF` | 直接切图 |
| 1 | `31` | `31 CE` | 交叉淡入淡出 |
| 2 | `32` | `32 CD` | 柔边滑动替换 |
| 3 | `33` | `33 CC` | 关闭 OSD |
| 4 | `34` | `34 CB` | 调整后显示 OSD 3 秒 |
| 5 | `35` | `35 CA` | 始终显示 OSD |
| R | `52` | `52 AD` | 原图 |
| G | `47` | `47 B8` | 灰度 |
| B | `42` | `42 BD` | 二值化 |
| E | `45` | `45 BA` | Sobel 梯度 |
| H | `48` | `48 B7` | 锐化 |
| W | `57` | `57 A8` | 雪花 |

## 音频频谱

| 按键 | CMD | 完整发送帧 | 作用 |
|---|---:|---:|---|
| Q | `51` | `51 AE` | 频谱开关 |
| ' | `27` | `27 D8` | 频谱灵敏度增加 |
| ; | `3B` | `3B C4` | 频谱灵敏度降低 |

灵敏度范围为 0 到 3；音量范围为 0 到 8；亮度范围为 0 到 8；对比度范围为 0 到 6。

## 状态与调试命令

| 按键 | CMD | 完整发送帧 | 说明 |
|---|---:|---:|---|
| I | `49` | `49 B6` | 查询 SD 状态 |
| D | `44` | `44 BB` | 调试用图像探针/快照命令；不作为日常媒体控制 |
| L | `4C` | `4C B3` | 旧版诊断命令；当前链路不提供常规有效响应 |

网页 D 快照和板间 `0x0040` SET / `0x0041` ACK 是另一层控制路径，不要把它们与这里的 UART 命令字节混淆。比如 `41 BE` 是 UART 的自动轮播命令帧；`0x0041` 是板间 ACK 包类型。

## 快速验证

1. 在 HEX 模式发送 `41 BE`，自动轮播应开/关一次。
2. 发送 `4E B1`，应执行下一张。
3. 若重新下载桌面独立项目 `hc08_hex_probe` 的测试 bit，用 TEXT 模式发送 `N`，数码管右侧显示 `4E`，字节计数加一；这是原始接收测试，不代表生产命令帧已经完整。
