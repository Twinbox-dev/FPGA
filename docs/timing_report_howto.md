# 时序报告怎么查（TD / Tang Dynasty）

> 2026-09-27 由"上板故障 ↔ 仿真全绿"的定位过程沉淀。以后任何综合后发现板级行为异常，
> **第一步永远是看时序报告**，别像这次一样先把 RTL 翻个底朝天——仿真管不着建立时间。

## 看什么

打开后按顺序看四处：

1. **Timing Status**（文件前部）：
   ```
   SWNS: -17.672ns   ← Worst Negative Slack，最差建立时间余量，负 = 违例
   STNS: -756.131ns  ← Total Negative Slack，全部违例之和
   HWNS: 0.030ns     ← Hold 最差余量（保持时间，一般不用管，工具会修）
   ```
   **经验阈值**：|WNS| < 1ns 且违例端点少 → 通常是 SDC 约束小瑕疵，板级大概率正常；
   |WNS| > 2ns → 有真实长组合链，板上必出随机错；|WNS| > 5ns → 功能必挂（本项目两次踩坑都是这类）。

2. **Clock Summary**：确认各时钟频率和扇出，心里有数（sd_card_clk 100M = 10ns 周期，
   违例 1ns 就是 10% 周期）。

3. **Max Paths**（违例路径明细）：每条给出
   - `Begin Point` / `End Point`：起点/终点寄存器（含层次路径，如 `sd_card_bmp_m0/first_idx_r_reg`）
   - `Logic Level`：逻辑级数。**>15 级就要警惕**（本项目爆炸链 33 级 / 27ns）；
   - `Data Path Delay`：总延迟；`Slack`：余量。
   定位技巧：`Begin Point` 的模块名告诉你病根在哪个文件——`u_fat` 开头 = fat32_ro，
   `frame_fifo_read_m0` = 读引擎，`U3` = SDRAM 例程核（加密 IP，动不了）。

4. **Statistics 各组**：报告按时钟域/分组列出 `Viol Endpoints`（违例端点数）。
   端点数多 = 大面积违例（布线拥塞）；端点数少但 slack 大 = 个别巨链。

## 本项目遗留的"基线违例"（不用慌，但要知道）

- **U3 SDRAM dq 组**（-6.5ns 档）：SDRAM 数据输入捕获路径，时钟偏斜 4.17ns 来自 PLL
  相位配置，加密例程核内部，改不了。图像版（8974d52）同样违例且上板工作正常，
  视为"报告很响、实际有余量"。判断标准：如果改了别的之后板子行为变化，再回头怀疑它。
- HDMI PHY / IIC 等例程自带路径偶发 -1~-3ns：同上看基线对比。

## 案例三（2026-09-27）：重综合把"临界链"挤过线，mount 卡死

- 现象：重综合上板后数码管停在 2（sd_init_done=1 但 fat_mounted=0），图/音/按键全无。
- 报告：全局 SWNS -6.565ns 吓人，但那是 clk2=ext_mem_clk 的 U3 基线（见上）；
  **真凶是 clk0（sd_card_clk 100MHz）组 -1.784ns / 109 端点**，全在 fat32_ro
  簇号→LBA 链（spc→log2s→桶形移位→add15×4→rd_lba）。挂载每读一个扇区都走
  这条链，地址错 → mount 永远完不成。上一轮同链在临界线内（能挂载），重布线挤过线。
- 修复：fat32_ro 拆流水——BPB 派生乘法独拍（S_BPB2）、簇→LBA 拆
  (簇-2)<<spc_log2 存 clu_lba + 单加法（S_LBA）、簇内推进直接 rd_lba+1。
  每扇区读 16384 拍，多两拍零成本；回归 7 卡周期数逐卡不变（纯时序重构）。
- 教训：**"上次能跑"≠"这次没问题"**。每次重综合都重看 clk0/clk1（用户时钟域）
  分组；全局 SWNS 大不一定致命，先按时钟域分组找自己模块的端点。
  |WNS|<2ns 的用户域违例也能致命——只要它恰好是每拍都走的路径（如 mount）。

## 排查 SOP（板级异常时）

1. 复现现象，记录操作序列；
2. 打开 `final_timing.rpt` 看 SWNS 和违例端点归属模块；
3. 仿真（boardtest）复现同一卡镜像——仿真绿 + 时序违例 ⇒ 时序问题，修 RTL 结构
   （长链拆流水、查表替代组合函数、加同步器）；
4. 仿真也复现 ⇒ 逻辑 bug，仿真里调试；
5. 修完必须重跑 phy 看新报告确认违例消除，不能只跑仿真。
