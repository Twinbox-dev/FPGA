以太网连接

板卡固定 192.168.137.2:1，回包发本机 192.168.137.1:2—— 本机网卡需有 192.168.137.1/24（子网掩码 255.255.255.0），网线直连即可。
首次连接 Windows 防火墙会询问是否放行 python 监听 UDP 端口 2，选「允许」。
命令帧与串口同款 [CMD,~CMD]，UDP 载荷 = 8 字节应用头 + 2 字节命令。
先点「连接」再发命令；板卡侧 UDP 无连接，未收到 ACK 先查网线与 IP 网段。
