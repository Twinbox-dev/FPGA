# 媒体板工程

本目录用于第二块 HX4S20C 的自包含 TD 工程。目标职责是 TF/SD、FAT32、
BMP/WAV 解析、播放列表、PC 控制和板间媒体发送；显示板工程在
[`../board_display/`](../board_display/) 中。

第一阶段工程为 [media_net.al](td_project/media_net.al)：复制了完整的以太网
RTL 和厂商 IP，独立使用本目录源码，不引用显示板的 Verilog。现在只有网络
连通性顶层，尚未接入 SD、媒体解析或板间图像数据。显示板仍使用原有单板固件。

- PC：`192.168.137.1`；显示板：`.2`；媒体板：`.3`，独立 MAC `02:00:00:00:00:03`。
- 媒体板收 UDP `:1` 上的原有应用头和 `[CMD, ~CMD]`，固定向 PC 的 `:2` 回送
  16 字节包。应用数据为 `E1 CMD 45 4D 00 00 00 00`，其中 `45 4D` 是 `EM` 标记。
  此阶段的应答只是连通性探针，不执行控制命令。
- 烧录并接入同一交换机后，先关闭占用 PC UDP `:2` 的 Web 控制台，再运行
  `python scripts/media_eth_probe.py`。每次 `S` 应打印 `media board reply OK`。
  运行前可先 `ping 192.168.137.3` 检查链路。
- 以太网子系统与其 50 MHz 命令桥均只在上电后复位一次；重新开始网络测试须
  重新烧录或断电上电。

端口约束复用了显示板已验证的以太网和时钟引脚。首次 TD 综合和板级网络测试
尚未完成；生成 bit 后需确认资源、时序和实际通信，再增加板间协议。
